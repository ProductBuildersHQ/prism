## [v0.1.0] - 2026-07-25 ([`f3a59f4`](https://github.com/ProductBuildersHQ/prism/commit/f3a59f4))

### Highlights

- Ent-backed domain store (MySQL dialect targeting Dolt) with an in-memory MemStore fake, so all domain logic is unit-testable without a running database
- Full delivery model: initiatives, phases with derived status, roadmap items (RMIs), lease-based work assignments, and delivery evidence
- One shared service layer powers both the `prismctl` Cobra CLI and an MCP server exposing 9 tools for Claude Code session integration
- Bidirectional ROADMAP.md sync, git commit ingestion for `Refs:` trailers, and JSONL snapshot export for portable backups

### Added

- Ent schema and generated code for Initiative, Phase, RoadmapItem, Assignment, DeliveryEvidence, Repository, and their dependency edges ([`db4d1eb`](https://github.com/ProductBuildersHQ/prism/commit/db4d1eb))
- Store interface with sub-interfaces for initiatives, phases, RMIs, assignments, evidence, and repositories, plus a MemStore in-memory fake, an Ent-backed DoltStore implementation (embedded and server modes), and typed error kinds in `pcerr` ([`5a5fd93`](https://github.com/ProductBuildersHQ/prism/commit/5a5fd93))
- Core domain packages: initiative lifecycle with phase status always derived from member RMIs, lease-based work assignments (claim/release/renew/complete), commit trailer parsing for `Refs:` and `Co-authored-by`, and RMI status/dependency tracking ([`acd03da`](https://github.com/ProductBuildersHQ/prism/commit/acd03da))
- ROADMAP.md parser, generator, and diff for bidirectional sync between markdown specs and the database; git commit ingestion for `Refs:` trailers and structured-changelog import; JSONL snapshot export with manifest for portable backups ([`ad376da`](https://github.com/ProductBuildersHQ/prism/commit/ad376da))
- Initiative report generation (markdown and JSON), dependency-ordered release planning, git repository scanning via gogit for commit attribution, and store-wide consistency validation (ID format, dangling dependencies, cycles, expired leases, status coherence, evidence coverage) ([`0832dfa`](https://github.com/ProductBuildersHQ/prism/commit/0832dfa))
- Shared service layer called identically by the CLI and MCP adapters (initiative CRUD, phase management, RMI operations, work claims with lease enforcement, roadmap sync, ingestion, reports, validation, export) and an MCP server exposing 9 tools over stdio transport ([`c60ed09`](https://github.com/ProductBuildersHQ/prism/commit/c60ed09))
- Root `prismcontrol` package as the importable SDK facade ([`0b62479`](https://github.com/ProductBuildersHQ/prism/commit/0b62479))
- Full `prismctl` Cobra CLI: database management (init, serve, create-views), a two-level dashboard (live server and static snapshot), registry, initiatives (CRUD, dependencies, program grouping), phases, RMIs (CRUD, dependencies, bulk status), work assignments (claim, release, renew, complete), roadmap sync, ingestion, reports, validation, export, and an MCP server launcher ([`64c1a4f`](https://github.com/ProductBuildersHQ/prism/commit/64c1a4f))

### Changed

- Gated all doltstore-importing code behind a `dolt` build tag so `go build`, `go test`, and `golangci-lint run` work without CGO or ICU headers; full Dolt functionality now requires `-tags dolt` ([`d536cc5`](https://github.com/ProductBuildersHQ/prism/commit/d536cc5))
